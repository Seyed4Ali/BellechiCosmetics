# BellechiCosmetics
# 💄 Bellechi Cosmetics

یک پلتفرم فروشگاهی برای محصولات آرایشی و بهداشتی با رابط کاربری مدرن، ساخته شده با **React + FastAPI + Docker**.

---

## 🚀 ویژگی‌ها (Features)

- رابط کاربری مدرن و واکنش‌گرا (Responsive UI)
- بک‌اند سریع با FastAPI
- سیستم احراز هویت JWT
- مدیریت محصولات، دسته‌بندی‌ها و سفارشات
- Docker-ready برای اجرا در هر محیط
- معماری جداگانه Frontend / Backend
